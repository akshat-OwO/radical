# 0009: Network status

Use the official [Capacitor Network API](https://capacitorjs.com/docs/apis/network) through the existing bridge listener mechanism introduced for video streams. Pin `@capacitor/network@8.0.1` in the manifest, catalog, and optional peer. `internalPlugins.network` is opt-in because apps without this capability do not need its native dependency. Network status needs no permission prompt.

Keep upstream field names, `connected` and `connectionType`. Connectivity describes an active local connection, not internet or server reachability. Native types are wifi, cellular, none, and unknown. The shared schema also accepts browser types ethernet, bluetooth, wimax, and other. Offline browsers normalize type to none. Browsers read `navigator.onLine`, subscribe to online/offline events, and read and subscribe to `navigator.connection` when available. Do not infer wifi from effective bandwidth or effectiveType; browsers without transport information report unknown.

Expose a current-status Effect and a cold Stream of status changes, with an injectable BrowserNetwork service and Live layer. Each subscription acquires its listener before reading current status. If an event arrives during the read, discard the read's response so it cannot overwrite a newer event. Decode native responses and events with Schema and preserve typed bridge errors. Malformed events fail the subscription and release its listener. A one-value sliding buffer bounds memory for slow consumers, and consecutive equal statuses do not cause rerenders.

The hook subscribes only after commit. SSR and hydration start loading with no value, rather than claiming offline without evidence. It interrupts its fiber and removes its listener on unmount or provider replacement, suppressing callbacks from retired subscriptions. Reuse the scoped listener release from ADR 0007. Do not remove all plugin listeners, since another consumer may own a separate subscription. Each mounted hook owns its own listener; no global mutable cache or polling timer is needed.
