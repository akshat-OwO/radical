## `getNativeContext(request)`

Returns `Effect<NativeContext>` without a typed failure. Prefers `x-radical-context` whenever the header is present. Otherwise reads the `radical-context` cookie. The reader does not authenticate the header or check its origin. URI decoding or schema failure returns browser context.

| Field          | Native value                   | Browser value |
| -------------- | ------------------------------ | ------------- |
| `platform`     | `"android"` or `"ios"`         | `"browser"`   |
| `safeArea`     | `{ top, right, bottom, left }` | Zero insets   |
| `shellVersion` | Nonempty string                | `null`        |

Insets are finite, nonnegative CSS pixel values. Native context is untrusted presentation data.

## `withBundledRequests(handler, outputs?)`

Returns a Promise-based fetch handler. Allows credentialed CORS for `https://localhost` and `capacitor://localhost` only. Other callers retain the handler's normal behavior without a CORS grant.

`handler` accepts a `Request` and returns `Response | Promise<Response>`. The optional `outputs` argument has type `Pick<AdapterOutputs, "exposedHeaders">` and defaults to `{}`.

Allowed preflights return 204 with methods `GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS` and the requested headers. They bypass `handler` and vary on `Origin` and `Access-Control-Request-Headers`. Every response from `handler` varies on `Origin`.

For allowed origins, the wrapper appends `outputs.exposedHeaders` to `Access-Control-Expose-Headers`. It adds no exposed headers by default or when the array is empty. Existing exposed headers remain unchanged.

The [TanStack Start wrapper](/docs/reference/vite#radicaltanstack-start-server) from `radical/tanstack-start-server` supplies the adapter outputs. It exposes `x-tss-serialized`, `x-tss-raw`, and `x-tss-error` to bundled clients.

The wrapper does not authenticate callers or replace the framework's CSRF configuration.

## Other server exports

`safeAreaStyle(context?, mode?)` returns the document CSS variables. Missing context uses browser defaults. `SafeArea` is an exported type. `NativeContext` is available from `radical/native-context`.

`radical/native-context` exports the context schemas, cookie and header constants, `encodeNativeContextCookie`, `safeAreaStyle`, `zeroSafeArea`, and context types. `encodeNativeContextCookie` returns an Effect encoding a shell context as URI-encoded JSON.
