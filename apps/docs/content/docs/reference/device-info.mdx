## Plain API

`getDeviceInfo()` from `@akshatowo/radical/client` returns `Promise<DeviceInfo>`. `useDeviceInfo()` exposes loading, value, and error state. `openAppSettings()` opens the app's page in system Settings and returns `Promise<void>`.

## Effect API

The contracts below use `@akshatowo/radical/effect/client`. See the [Effect API guide](/docs/guides/effect-api) for runtime composition.

`internalPlugins.device` defaults to true. The native dependency is `@capacitor/device`, with the package's declared compatible version range `^8.0.3`.

`getDeviceInfo` is an Effect of `DeviceInfo` requiring `Bridge`, with `BridgeError` failures. `openAppSettings` is an Effect of `void` requiring `Bridge`; it fails with `Unavailable` in a browser.

`internalPlugins.device` also adds the `RadicalSettings` native plugin that backs it. `DeviceInfoSchema` validates the common result.

| Field | Values |
| --- | --- |
| `platform` | `"android"`, `"ios"`, or `"web"` |
| `model` | String |
| `operatingSystem` | `"android"`, `"ios"`, `"windows"`, `"mac"`, `"linux"`, or `"unknown"` |
| `osVersion` | String |
| `manufacturer` | String |
| `isVirtual` | Boolean |

| Browser field or API | Contract |
| --- | --- |
| `browserDeviceInfo({ userAgent, userAgentData? })` | Synchronous user-agent derivation |
| `platform` | `"web"`, unlike native context `"browser"` |
| `model`, `manufacturer` | `"unknown"` |
| `isVirtual` | `false`; user agents cannot reliably identify emulators |
| `osVersion` | May be unknown with reduced user-agent information |

- `useDeviceInfo()` returns `DeviceInfoState` with loading, value, and error fields.
- The effect starts after mount.
- Native failures use bridge error tags.

## Platform support

| Capability | Android | iOS | Browser |
| --- | --- | --- | --- |
| Device result | Capacitor device info | Capacitor device info | Derived user-agent info |
| `openAppSettings` | App details screen | App page in Settings | `Unavailable` |
