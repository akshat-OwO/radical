---
title: "Google sign-in API"
description: "Native identity tokens and browser service injection."
---

Native enablement is `internalPlugins.googleSignIn`. The dependency is `@capawesome/capacitor-google-sign-in@0.1.4`.

`GoogleSignInConfigSchema` validates `webClientId` and `iosClientId`. Each identifier matches letters, digits, underscores, or hyphens followed by `.apps.googleusercontent.com`. `pluginOptions.GoogleSignIn` supplies the config. Generation defines the runtime config and writes the iOS client identifier and reversed URL scheme.

`googleSignIn` is an Effect of `GoogleIdentity`, requiring `Bridge | BrowserGoogleSignIn | GoogleSignInConfiguration`. `GoogleIdentitySchema` validates `{ idToken: nonempty string }`.

`googleSignInLive(effect)` supplies `BrowserGoogleSignInLive` and `GoogleSignInConfigurationLive`. The default browser service fails with `GoogleSignInUnavailable`. The browser service can be replaced with an app-owned OAuth flow. Native code initializes the plugin with `webClientId` before sign-in.

## Typed errors

`GoogleSignInError` is `BridgeError | GoogleSignInCancelled | GoogleSignInMisconfigured | GoogleSignInUnavailable`.

| Error | Meaning |
| --- | --- |
| `GoogleSignInCancelled` | Native sign-in rejects with `SIGN_IN_CANCELED`. |
| `GoogleSignInMisconfigured` | Missing runtime config, initialization failure, or `PROVIDER_CONFIGURATION_ERROR`. Carries `cause`. |
| `GoogleSignInUnavailable` | The default browser service cannot sign in. |
| `BridgeCallFailed` | Other native rejection. |
| `BridgeDecodeError` | Invalid native identity result. |

`useGoogleSignIn()` exposes `signIn()`, `cancel()`, loading state, `value.idToken`, and `error`. Interrupting the Effect does not provide a native sign-out API. Radical does not verify tokens or create an application session.
