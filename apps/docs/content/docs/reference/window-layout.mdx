---
title: Window layout
description: Width classes, fold posture, hinge CSS, and layout subscriptions.
---

`NativeContext.windowLayout` contains:

| Field | Values |
| --- | --- |
| `widthClass` | `compact` below 600 CSS pixels, `medium` from 600 to below 840, `expanded` at 840 and above |
| `posture` | `flat`, `tabletop`, or `book` |
| `hinge` | `null` or `{ x, y, width, height }`, finite nonnegative CSS pixels relative to the window |

Missing or invalid layout defaults to `{ widthClass: "compact", posture: "flat", hinge: null }` without discarding other valid context fields.

| API | Behavior |
| --- | --- |
| `useWindowLayout()` | Returns `WindowLayout` directly. Uses provider context for SSR and hydration, then live values after mount. |
| `watchWindowLayout(receive)` | Effect requiring `Bridge \| Scope`. Returns cleanup and runs it on scope closure. Replays the latest shell layout. |
| `windowLayoutStyle(context?, mode = "remote")` | Returns `--radical-hinge-x`, `--radical-hinge-y`, `--radical-hinge-width`, and `--radical-hinge-height`. Missing hinges use `0px`. Bundled style props stay at `0px` while native CSS supplies live values after mount. |
| Native event | `radicalWindowLayout`. Invalid events are ignored. |

| Platform | Layout source |
| --- | --- |
| iOS | View bounds. Always `flat`, no hinge. |
| Android | Activity window and Jetpack WindowManager. Half-open horizontal folds report `tabletop`; vertical folds report `book`. Other states report `flat`. Folding features supply hinge bounds, including zero-width folds. |
| Browser | `matchMedia` at 600 and 840 CSS pixels. Always `flat`, no hinge. |

`windowLayoutStyle` supplies hinge variables on `<html>` from the first render. Without it, the shell adds them after mount to preserve hydration. See [Adapt to window layout](/docs/guides/window-layout).

| Export | Entry point |
| --- | --- |
| `useWindowLayout`, `WindowLayout` | `@akshatowo/radical/react`, `@akshatowo/radical/effect/react` |
| `windowLayoutStyle`, `WindowLayout` | `@akshatowo/radical/client`, `@akshatowo/radical/server`, `@akshatowo/radical/native-context`, and their `effect/` equivalents |
| `watchWindowLayout` | `@akshatowo/radical/effect/client` |
| `WindowLayoutSchema`, `defaultWindowLayout` | `@akshatowo/radical/effect/native-context` |
