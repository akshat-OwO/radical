- Hooks do not invoke browser APIs during render.
- Effects start after commit.
- Unmount and provider replacement interrupt pending work and remove owned listeners.
- Action hooks suppress overlapping actions.
- A native picker can remain visible after interruption.

## Hook contracts

| Hook | Actions and result |
| --- | --- |
| `useDeviceInfo()` | Starts after mount. `{ loading, value, error }`. Value is `DeviceInfo`. |
| `useSections()` | Returns `sections`, `active`, `hidden`, `select(id)`, and `setBadge(id, value)`. Requires `TanStackSections`; see [Sections](/docs/reference/sections). |
| `useWindowLayout()` | Returns `{ widthClass, posture, hinge }`. Uses provider layout until mount, then live updates. |
| `useSafeArea()` | Returns `SafeArea` directly. Initial provider insets, then live updates. |
| `useCamera()` | `capture()`, `choose()`, `loading`, `value?: Photo`, `error`. |
| `useCameraPermission()` | `check()`, `request()`, `loading`, `value?: CameraPermission`, `error`. Checks after mount. |
| `useFilePicker()` | `pick(options?)`, `loading`, `value?: readonly PickedFile[]`, `error`. |
| `useIntent()` | `openUrl(url)`, `openFile(file, options?)`, `loading`, `value?: true`, `error`. |
| `useVideoStream(options)` | `start()`, `stop()`, `switchCamera()`, `setZoom(level)`, `setTorch(enabled)`, `running`, `loading`, `value?: VideoStreamInfo`, `error`. |
| `useHapticFeedback()` | `light()`, `medium()`, `heavy()`, `success()`, `warning()`, `error()`, `selection()`, `impact(style?)`, `loading`, `value?: true`, `failure`. |
| `useNetworkStatus()` | Live `{ loading, value?: NetworkStatus, error }`. |
| `useLocation()` | `getCurrent(options?)`, `loading`, `value?: LocationFix`, `error`. |
| `useLocationPermission()` | `check()`, `request(options?)`, `loading`, `value?: LocationPermission`, `error`. Checks after mount and updates when permission changes through any API. Denial resolves `state: "denied"`. |
| `useLocationWatch()` | `start(options?)`, `stop()`, `running`, `loading` until the first location fix, `value?: LocationFix`, `error`. Transient errors set `error` and keep the watch running; the next location fix clears it. `start` and `stop` are stable. Stops on unmount. |
| `useGoogleSignIn()` | `signIn()`, `cancel()`, `loading`, `value?: GoogleIdentity`, `error`. |
| `useNotificationPermission()` | `check()`, `request()`, `loading`, `value?: NotificationPermission`, `error`. Checks after mount. |
| `useExactAlarmPermission()` | Checks after mount; `check()`, `request()`, `loading`, `value?: ExactAlarmPermission`, `error`. |
| `useNotifications()` | `schedule(notification)`, `cancel(id)`, `setBadge(count)`, `clearBadge()`, `registerPush()`, `subscribe(topic)`, `unsubscribe(topic)`, `lookupTopics()`, `loading`, `value`, `error`. |
| `useDataProtection()` | `setEnabled(enabled)`, `clearWebData()`, `loading`, `value?: DataProtectionStatus \| true`, `error`. |

The video hook accepts `{ viewfinder: RefObject<HTMLElement | null>, facing?, onDetect? }`. Its `loading` represents startup. `running` represents an acquired session.

- `useNotifications().cancel(id)` cancels a scheduled reminder.
- Its `value` is a `NotificationScheduleResult`, push-token string, readonly topic list, or `true` for other completed actions.
- Haptics uses `failure` because `error()` sends feedback.

Device and network hooks start with `loading: true`, undefined `value`, and undefined `error` during SSR and initial hydration. Action hooks start idle.

## Exported types and errors

Each hook exports its named state type, such as `CameraState`, `NetworkStatusState`, and `DataProtectionState`. `DeviceInfo`, `SafeArea`, `BridgeError`, camera types, file types, video result types, haptic types, network types, location types, Google identity types, and data-protection types are re-exported here.

`PermissionDenied`, `Cancelled`, `Unavailable`, `NoHandler`, `LocationServicesOff`, `LocationTimeout`, `GoogleSignInCancelled`, `GoogleSignInMisconfigured`, and `GoogleSignInUnavailable` are exported error classes. Notification types and errors are available from `@akshatowo/radical/client`; schemas are available from `@akshatowo/radical/effect/client` rather than `@akshatowo/radical/react`.

Source: [React exports](https://github.com/akshat-OwO/radical/blob/main/packages/radical/src/react/react.ts).

- `useRadicalRuntime()` returns the provider handle.
- Pass it to `createPluginClient(manifest, runtime)` or generated `createPlugins(runtime)` to use the same bridge as the hooks.
- A supplied runtime belongs to the caller, which calls `await runtime.dispose()`.
- The Effect API provider at `@akshatowo/radical/effect/react` also accepts `layer` for service injection.
