title: "Build a maps app"
description: "Create a TanStack Start app with a live map, show the user's location, follow it, and run it on the web, Android, and iOS."
---

<Callout type="info">
  The location capability is available in `@akshatowo/radical` 0.3.0 and later.
</Callout>

In this tutorial you build a one-screen maps app and run the same code in a browser, an Android emulator, and an iOS simulator. The app shows where the user is, follows them as they move, and measures the distance to pins they drop on the map.

You use the same stack as the [todo tutorial](/docs/tutorials/todo-app): TanStack Start, Tailwind CSS v4, and Radical in remote mode. The map comes from [mapcn](https://www.mapcn.dev/), a shadcn component that wraps MapLibre GL, with free tiles from [OpenFreeMap](https://openfreemap.org/).

## Before you start

You need:

- Node.js 22.18 or later and pnpm.
- Android Studio with an emulator, for the Android step.
- macOS with Xcode and an iOS simulator, for the iOS step.

You can finish the web part without either native toolchain. A browser asks for location only on `localhost` or an HTTPS origin.

## Create the project

Create a TanStack Start app with the TanStack CLI:

```sh
npx @tanstack/cli@latest create maps --framework React --package-manager pnpm --no-examples --no-toolchain
cd maps
```

The standard template includes Tailwind CSS v4 and maps both `#/*` and `@/*` to `src/`. This tutorial uses `@/*`, because shadcn components import from it.

## Add Radical

Install Radical and allow its `sharp` build script:

```sh
pnpm add @akshatowo/radical
pnpm approve-builds sharp
```

### Configure Vite

Replace `vite.config.ts`:

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import {
  radical,
  tanstackStartOptions,
} from "@akshatowo/radical/tanstack-start";
import type { RadicalConfig } from "@akshatowo/radical/vite";
import { tanstackStart } from "@tanstack/react-start/plugin/vite";
import viteReact from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

const config = {
  appId: "dev.example.maps",
  name: "Maps",
  mode: "remote",
  devHost: "localhost",
  internalPlugins: { location: true },
  pluginOptions: {
    Location: {
      usageDescription: "Maps shows where you are on the map.",
      precisePurposes: {
        followMe: "Maps follows your exact position while you walk.",
      },
    },
  },
} satisfies RadicalConfig;

const viteConfig = defineConfig({
  resolve: { tsconfigPaths: true },
  plugins: [
    tailwindcss(),
    tanstackStart(tanstackStartOptions(config)),
    radical(config),
    viteReact(),
  ],
});

export default viteConfig;
```

`internalPlugins.location` adds the native location plugins. `usageDescription` is the text iOS shows when the app first asks for location. The `followMe` key in `precisePurposes` names the one feature that needs precise location; iOS shows its text when the app asks for precise location after the user chose approximate.

Like the todo tutorial, this config leaves out the generated `devtools()` plugin.

### Include generated types

Add Radical's generated plugin types to the `include` list in `tsconfig.json`:

```json title="tsconfig.json"
{
  "include": ["**/*.ts", "**/*.tsx", ".radical/plugins.d.ts"]
}
```

Then add `.radical/` to `.gitignore`.

### Register the request middleware

Create `src/start.ts`:

```ts title="src/start.ts"
import { createStart } from "@tanstack/react-start";
import { createRadicalRequestMiddleware } from "@akshatowo/radical/tanstack-start-server";

export const startInstance = createStart(() => ({
  requestMiddleware: [...createRadicalRequestMiddleware()],
}));

declare module "@tanstack/react-start" {
  interface Register {
    config: Awaited<ReturnType<typeof startInstance.getOptions>>;
  }
}
```

The middleware reads the device details that the shell sends with each request, such as the safe-area insets, and adds `nativeContext` to the server context.

### Update the root route

Replace `src/routes/__root.tsx`:

```tsx title="src/routes/__root.tsx"
import { HeadContent, Scripts, createRootRoute } from "@tanstack/react-router";
import { createServerFn } from "@tanstack/react-start";
import { safeAreaStyle } from "@akshatowo/radical/client";
import { RadicalProvider } from "@akshatowo/radical/react";
import type { CSSProperties, ReactNode } from "react";

import appCss from "../styles.css?url";

const readNativeContext = createServerFn({ method: "GET" }).handler(
  ({ context }) => context.nativeContext
);

export const Route = createRootRoute({
  loader: async () => ({ nativeContext: await readNativeContext() }),
  head: () => ({
    meta: [
      { charSet: "utf-8" },
      {
        name: "viewport",
        content: "width=device-width, initial-scale=1, viewport-fit=cover",
      },
      { title: "Maps" },
    ],
    links: [
      { rel: "preconnect", href: "https://fonts.googleapis.com" },
      {
        rel: "preconnect",
        href: "https://fonts.gstatic.com",
        crossOrigin: "anonymous",
      },
      {
        rel: "stylesheet",
        href: "https://fonts.googleapis.com/css2?family=Chivo+Mono:wght@400;500;800&display=swap",
      },
      { rel: "stylesheet", href: appCss },
    ],
  }),
  shellComponent: RootDocument,
});

function RootDocument({ children }: { children: ReactNode }) {
  const { nativeContext } = Route.useLoaderData();
  const rootStyle: CSSProperties & ReturnType<typeof safeAreaStyle> =
    safeAreaStyle(nativeContext, "remote");

  return (
    <html lang="en" style={rootStyle}>
      <head>
        <HeadContent />
      </head>
      <body>
        <RadicalProvider nativeContext={nativeContext}>
          {children}
        </RadicalProvider>
        <Scripts />
      </body>
    </html>
  );
}
```

This is the todo tutorial's root with a different title and font. The loader reads `nativeContext` on the server, `safeAreaStyle` sets the `--radical-safe-area-*` variables, and `RadicalProvider` connects the capability hooks to the bridge.

### Install mapcn

Add the map component:

```sh
pnpm dlx shadcn@latest add @mapcn/map
```

The CLI writes `src/components/ui/map.tsx` and installs `maplibre-gl` 6, `lucide-react`, and `@types/geojson`. It also adds a `@layer base` block for MapLibre's popups and attribution to `src/styles.css`. The next section replaces that file and keeps the block.

### Serve the MapLibre worker yourself

MapLibre parses tiles in a web worker. mapcn loads the worker script from a CDN by default. Copy it into `public/`, so the app does not depend on a third-party script host:

```sh
mkdir -p public
cp node_modules/maplibre-gl/dist/maplibre-gl-worker.mjs node_modules/maplibre-gl/dist/maplibre-gl-shared.mjs public/
```

Then point mapcn at the copy. In `src/components/ui/map.tsx`, find `loadMapLibre` and replace the `setWorkerUrl` line:

```ts title="src/components/ui/map.tsx"
function loadMapLibre() {
  maplibrePromise ??= import("maplibre-gl")
    .then((lib) => {
      if (!lib.getWorkerUrl()) {
        lib.setWorkerUrl("/maplibre-gl-worker.mjs"); // [!code ++]
      }
      return lib;
    })
    .catch((error) => {
      maplibrePromise = null;
      throw error;
    });
  return maplibrePromise;
}
```

Copy both files again when you upgrade `maplibre-gl`.

### Choose the map styles

mapcn's default CARTO styles need an API key. Create `src/lib/map.ts` with OpenFreeMap styles, which need none, and a distance formatter:

```ts title="src/lib/map.ts"
export const mapStyles = {
  light: "https://tiles.openfreemap.org/styles/positron",
  dark: "https://tiles.openfreemap.org/styles/dark",
};

export const formatDistance = (metres: number) =>
  metres < 1000
    ? `${Math.round(metres)} m`
    : `${(metres / 1000).toFixed(metres < 10_000 ? 1 : 0)} km`;
```

You pass `mapStyles` to the map's `styles` prop. OpenFreeMap also has `liberty` and `bright` styles.

## Build the maps screen

Start the dev server and keep it running for the rest of the tutorial:


### Step 1: Centre the map on a location fix

Create `src/components/center-on.tsx`:

```tsx title="src/components/center-on.tsx"

import { useEffect } from "react";

import { useMap } from "@/components/ui/map";

const metresPerDegree = 111_320;

export function CenterOn({
  fix,
  follow = false,
}: {
  fix?: LocationFix;
  follow?: boolean;
}) {
  const { map } = useMap();

  useEffect(() => {
    if (!map || !fix) return;

    if (follow) {
      map.easeTo({ center: [fix.longitude, fix.latitude], duration: 500 });
      return;
    }

    // Frame the whole accuracy circle, so an approximate fix shows its area.
    const lat = fix.accuracy / metresPerDegree;
    const lng = lat / Math.cos((fix.latitude * Math.PI) / 180);
    map.fitBounds(
      [
        [fix.longitude - lng, fix.latitude - lat],
        [fix.longitude + lng, fix.latitude + lat],
      ],
      { padding: 48, maxZoom: 16 }
    );
  }, [map, fix, follow]);

  return null;
}
```

`useMap` gives components inside `<Map>` access to the MapLibre map. Without `follow`, `CenterOn` frames the whole accuracy circle of the location fix, so an approximate location fix shows the area it covers instead of a false point. Step 4 uses `follow`.

```tsx title="src/components/user-location.tsx"
import type { LocationFix } from "@akshatowo/radical/react";
import { useEffect, useState } from "react";

import { MapMarker, MarkerContent, useMap } from "@/components/ui/map";

// MapLibre tiles are 512 px, so zoom 0 spans the equator in 512 px.
const metresPerPixel = (latitude: number, zoom: number) =>
  (40_075_016.686 * Math.cos((latitude * Math.PI) / 180)) / 2 ** (zoom + 9);

export function UserLocation({ fix }: { fix: LocationFix }) {
  const { map } = useMap();
  const [zoom, setZoom] = useState(() => map?.getZoom() ?? 0);

  useEffect(() => {
    if (!map) return;
    const update = () => setZoom(map.getZoom());
    update();
    map.on("zoom", update);
    return () => {
      map.off("zoom", update);
    };
  }, [map]);

  const diameter = (2 * fix.accuracy) / metresPerPixel(fix.latitude, zoom);

  return (
    <MapMarker longitude={fix.longitude} latitude={fix.latitude}>
      <MarkerContent className="cursor-default">
        <span
          className="accuracy"
          style={{ width: diameter, height: diameter }}
          aria-hidden="true"
        />
        <span
          className="user-dot"
          role="img"
          aria-label={`You are here, within ${Math.round(fix.accuracy)} metres`}
        />
      </MarkerContent>
    </MapMarker>
  );
}
```

The blue dot marks the location fix. The circle around it has a radius equal to the fix's `accuracy`, converted from metres to pixels at the current zoom. A small circle means a precise location fix; a wide one means the user is somewhere inside it.

- `useLocationWatch` keeps a native watch open while `watch.running` is true. `watch.value` holds the latest location fix. The hook stops the watch on unmount.
- **Follow me** asks for precise location if needed, then calls `watch.start({ enableHighAccuracy: true })`. `enableHighAccuracy` asks for the best fix the current grant allows. - While following, `CenterOn` eases the map to each new location fix instead of fitting the accuracy circle.
- `fix` keeps the newest location fix from either hook, so the dot stays where it was when you stop following.

The button drives the watch directly, so `watch.running` is the only follow-me state. If a watch should follow some other state instead, start it in an effect that returns `stop`, as the [location guide](/docs/guides/location#connect-actions) shows.

```ts title="src/lib/pins.ts"
import { useEffect, useState } from "react";

export type Place = { latitude: number; longitude: number };
export type Pin = Place & { id: string };

const key = "maps:pins";

const load = (): Pin[] => {
  try {
    return JSON.parse(localStorage.getItem(key) ?? "[]");
  } catch {
    return [];
  }
};

export function usePins() {
  const [pins, setPins] = useState<Pin[]>([]);

  // localStorage exists only in the browser, so read it after hydration.
  useEffect(() => setPins(load()), []);

  const save = (next: Pin[]) => {
    setPins(next);
    localStorage.setItem(key, JSON.stringify(next));
  };

  return {
    pins,
    add: (place: Place) =>
      save([...pins, { ...place, id: Date.now().toString(36) }]),
    remove: (id: string) => save(pins.filter((pin) => pin.id !== id)),
  };
}

const earthRadius = 6_371_008.8;
const radians = (degrees: number) => (degrees * Math.PI) / 180;

/** Great-circle distance in metres. */
export const distanceBetween = (a: Place, b: Place) => {
  const dLat = radians(b.latitude - a.latitude);
  const dLng = radians(b.longitude - a.longitude);
  const h =
    Math.sin(dLat / 2) ** 2 +
    Math.cos(radians(a.latitude)) *
      Math.cos(radians(b.latitude)) *
      Math.sin(dLng / 2) ** 2;

  return 2 * earthRadius * Math.asin(Math.sqrt(h));
};
```

The pins live in `localStorage`, on the device. `distanceBetween` is the great-circle distance in metres between two points.

```tsx title="src/routes/index.tsx"
  const blocked = blockedBy(
    permission.value,
    permission.error ?? watch.error ?? location.error
  );

  const retry = () => {
    permission.check();
    getCurrent();
  };

  const toggleFollow = () => {
    if (watch.running) {
      watch.stop();
      return;
    }
    if (permission.value?.precision === "approximate") {
      permission.request({ precise: "followMe" });
    }
    watch.start({ enableHighAccuracy: true });
  };

  return (
    <main className="screen">
      <header className="bar">
        <h1 className="text-lg">Maps</h1>
        <PermissionBadge permission={permission.value} />
      </header>

      <div className="relative min-h-0">
        <Map theme="light" styles={mapStyles} center={[0, 20]} zoom={1.5}>
          <CenterOn fix={fix} follow={watch.running} />
          {/* [!code ++:12] */}
          <DropPins onDrop={add} />
          {pins.map((pin, index) => (
            <MapMarker
              key={pin.id}
              longitude={pin.longitude}
              latitude={pin.latitude}
            >
              <MarkerContent className="cursor-default">
                <span className="pin">{index + 1}</span>
              </MarkerContent>
            </MapMarker>
          ))}
          {fix && <UserLocation fix={fix} />}
        </Map>
      </div>

      <section className="sheet" aria-label="Your location">
        {blocked ? (
          <LocationBlocked reason={blocked} onRetry={retry} />
        ) : fix ? (
          <div className="flex items-end justify-between gap-4">
            <p>
              <span className="figure">{formatDistance(fix.accuracy)}</span>
              <br />
              <span className="text-sm text-ink-3">accuracy</span>
            </p>
            <button
              type="button"
              className="btn"
              aria-pressed={watch.running}
              onClick={toggleFollow}
            >
              {watch.running ? "Following" : "Follow me"}
            </button>
          </div>
        ) : permission.value?.state === "prompt" ? (
          <button
            type="button"
            className="btn btn-primary"
            onClick={() => permission.request()}
          >
            Show where I am
          </button>
        ) : (
          <p className="text-ink-3">Finding you</p>
        )}
        {/* [!code ++] */}
        <PinList pins={pins} from={fix} onRemove={remove} />
      </section>
    </main>
  );
}
```

Tap the map to drop a pin. Each pin gets a number on the map and a row in the sheet, sorted by distance from your location fix. The caption repeats the fix's accuracy, because a distance is only as good as the location fix it starts from.

## Use mapcn's locate control

Map libraries call `navigator.geolocation` directly. In a shell, Radical replaces that API with one backed by the native plugin, so third-party controls work without changes. Add mapcn's controls to the map:

```tsx title="src/routes/index.tsx"
import {
  Map,
  MapControls, // [!code ++]
  MapMarker,
  MarkerContent,
} from "@/components/ui/map";

// Inside <Map>, after {fix && <UserLocation fix={fix} />}:
// [!code ++]
<MapControls position="top-right" showLocate />;
```

The locate button calls `navigator.geolocation.getCurrentPosition` and flies the map to the result. In a shell, that call goes through the same native plugin and permission as the hooks. If the user has not answered yet, it asks for approximate location, as a browser would. `useLocationPermission` updates by itself when the control's prompt changes the permission, so the badge changes and the page's effect reads its own location fix. The control needs no callback.

## Step 6: Run it on Android and iOS

Keep `pnpm dev` running. In remote mode each native shell loads the page from that server.

Install the native packages. The geolocation plugin backs the location hooks and the `navigator.geolocation` replacement:

```sh
pnpm add @capacitor/core@^8.5.3 @capacitor/android@^8.5.3 @capacitor/ios@^8.5.3 @capacitor/device@^8.0.3 @capacitor/geolocation@8.2.4
pnpm add -D @capacitor/cli@^8.5.3
```

### Android

Start an emulator from Android Studio's Device Manager, find its serial with `adb devices`, then forward the port and launch the app:

```sh
adb -s emulator-5554 reverse tcp:3000 tcp:3000
pnpm exec radical android --target emulator-5554
```

Set the emulator's location in **Extended controls > Location**. To test follow-me, load a route on the **Routes** tab and play it.

### iOS

List your simulators, copy a UDID, and launch the app:

```sh
xcrun simctl list devices available
pnpm exec radical ios --target YOUR_SIMULATOR_UDID
```

Set the simulator's location in **Features > Location**. Pick **Custom Location** for one place, or **City Run** to test follow-me.

### What to look for

The first prompt is the system's, not the browser's. **Show where I am** asks for approximate location on both platforms, and the badge reads **Approximate**. On Android 11 and earlier there is no approximate choice, so the badge reads **Precise** straight away.

Select **Follow me**. Android asks to upgrade to precise location. iOS shows your `followMe` text and asks for temporary precise location. The badge turns blue and reads **Precise**, and the accuracy circle shrinks. If you decline, the badge stays **Approximate** and the map still follows the approximate location fixes. On iOS, temporary precise location expires some time after you leave the app; until then, **Follow me** does not ask again.

On an Android emulator with Google Play services and Google Location Accuracy off, the first location fix shows Google's dialog. Accept it, and the location fix arrives in the same request.

Turn off location services: on Android in **Settings > Location**, on iOS in **Settings > Privacy & Security > Location Services**. Return to the app and select **Try again**. On Android with Google Play services, Google's dialog appears first; select **No thanks**. The plate reads **Location services are off**, and its button opens the Settings screen. The badge still shows the app's permission, because location services is a separate switch. On iOS the button opens the app's page in Settings, because iOS has no public link to the Location Services screen. Deny location for the app to see **Location is blocked** and **Open app settings** instead.

Select the locate control on the map. It uses `navigator.geolocation`, but you see no second prompt, because the replacement shares the app's native permission. On a fresh install, select the locate control first: it asks for approximate location, as a browser would, and the badge updates without any extra code.

On a phone the header starts below the status bar, and the sheet stays clear of the home indicator. When the app goes to the background, the watch pauses, and it resumes when you return.

### Bundled mode

The map runs in [bundled mode](/docs/guides/bundled-mode) too. Once the root reads native context on the device, the screen calls no server functions. The shell then loads the screen from files inside the app. Set `mode: "bundled"` and an `origin` in `vite.config.ts`, then follow the bundled-mode guide to switch the root route to `localNativeContext()`, disable SSR, and mount the native context after hydration.

Location works the same way in both modes. Map tiles still come from OpenFreeMap, so the map needs the network. The self-hosted MapLibre worker ships inside the app.
