Start with [Getting started](/docs/getting-started) to create your own TanStack Start project and install Radical. The guide includes every required configuration and source file.

1. [Install and run in the browser](/docs/getting-started/installation).
2. [Review the project structure](/docs/getting-started/project-structure).
3. [Launch Android or iOS](/docs/getting-started/native).

If you copied an older repository example, use the new installation page to check your request middleware, root provider, and SSR integration before adding capabilities.
