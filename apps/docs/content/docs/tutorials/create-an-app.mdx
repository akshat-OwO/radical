---
title: "Create and run a TanStack Start app"
description: "Build a Radical app from the repository example, then run its Android and iOS shells."
---

You create a TanStack Start app from the working example and run the same UI in a browser and native shells. You need Node.js 22.18 or newer, pnpm, and Vite+. For Android, install Android Studio, its SDK, a compatible JDK, and an AVD. For iOS, use macOS with Xcode and an installed iPhone simulator.

## Create your app from the example

1. Clone Radical and install its workspace dependencies:

```sh
git clone https://github.com/akshat-OwO/radical.git
cd radical
pnpm install
```

2. Build the package:

```sh
vp run radical#build
```

3. Copy the example into a new workspace app:

```sh
cp -R apps/example apps/my-app
```

4. In `apps/my-app/package.json`, change `name` to `@radical/my-app`.
5. Run `pnpm install` from the repository root.
6. In `apps/my-app/vite.config.ts`, replace the config object with this minimal remote-mode config. Keep the existing imports and plugin array:

```ts
const config = {
  appId: "dev.example.myapp",
  name: "My app",
  mode: "remote",
  devHost: "localhost",
} satisfies RadicalConfig;
```

7. Remove the `plugins` folder and `src/routes/index.tsx` from your copy. Replace `index.tsx` with this route, so the app does not import the example's Echo plugin:

```tsx
import { createFileRoute } from "@tanstack/react-router";
import { useDeviceInfo } from "radical/react";

const Home = () => {
  const device = useDeviceInfo();
  return (
    <main>
      <h1>My Radical app</h1>
      <pre>{JSON.stringify(device.error ?? device.value ?? "Loading")}</pre>
    </main>
  );
};
export const Route = createFileRoute("/")({ component: Home });
```

8. Remove `NotificationNavigation` and its rendered element from `src/routes/__root.tsx`. Remove the unused notification imports. Keep `RadicalProvider`, the native-context loader, and the document setup.
9. Remove the other example routes from `src/routes`. Keep `__root.tsx` and your new `index.tsx`. Keep `public/offline.html`.
10. Start the app:

```sh
vp -C apps/my-app dev --host 0.0.0.0 --port 5173
```

Open `http://localhost:5173`. You see **My Radical app** and browser device information. The Vite plugin records the server URL in `.radical/native.json`.

## Run Android

1. For an Android emulator, make the host server reachable through adb:

```sh
adb reverse tcp:5173 tcp:5173
```

2. In a second terminal, run the shell from the app directory:

```sh
cd apps/my-app
pnpm exec radical android
```

The CLI generates `.radical/android`, builds the debug APK, installs it, and opens the app. If no connected device exists, the CLI offers installed AVDs. You see the same heading with `platform: "android"` in device information.

## Run iOS

1. On macOS, run the shell from `apps/my-app`:

```sh
pnpm exec radical ios
```

The CLI selects a booted iPhone simulator or the first available iPhone, builds the app, and launches it. You see your heading and `platform: "ios"`. The simulator reaches the host's localhost server directly.

2. After you finish, stop the dev server with Control-C.

For a physical Android device, follow [Run on a device](/docs/guides/run-on-a-device). To package the UI, follow [Switch to bundled mode](/docs/guides/bundled-mode). The [example source](https://github.com/akshat-OwO/radical/tree/main/apps/example) contains the complete integration with optional capabilities.
