---
title: "Create and run a TanStack Start app"
description: "Build a Radical app from the repository example, then run its Android and iOS shells."
---

Build a browser app, then open the same UI in a native shell with [these prerequisites](/docs/guides/run-on-a-device#prerequisites).

<Steps>
<Step>

## Copy the example

Clone, build, and copy the working app:

```sh
git clone https://github.com/akshat-OwO/radical.git
cd radical
pnpm install
vp run radical#build
cp -R apps/example apps/my-app
```

You have `apps/my-app`.

</Step>
<Step>

## Rename the package

Set `apps/my-app/package.json`'s `name` to `@radical/my-app`, then run from the repository root:

```sh
pnpm install
```

</Step>
<Step>

## Set app identity

Replace the config object in `apps/my-app/vite.config.ts`, keeping imports and the plugin array:

```ts
const config = {
  appId: "dev.example.myapp",
  name: "My app",
  mode: "remote",
  devHost: "localhost",
} satisfies RadicalConfig;
```

</Step>
<Step>

## Replace example routes

Keep `__root.tsx` and `public/offline.html`; remove `plugins` and all other routes before creating `src/routes/index.tsx`:

```tsx
import { createFileRoute } from "@tanstack/react-router";
import { useDeviceInfo } from "radical/react";

const Home = () => {
  const device = useDeviceInfo();
  return (
    <main>
      <h1>My Radical app</h1>
      <pre>{JSON.stringify(device.error ?? device.value ?? "Loading")}</pre>
    </main>
  );
};
export const Route = createFileRoute("/")({ component: Home });
```

</Step>
<Step>

## Remove the notification watcher

Remove `NotificationNavigation`, its rendered element, and unused imports from `__root.tsx`, keeping `RadicalProvider`, the loader, and document setup.

</Step>
<Step>

## Open the browser app

Start from the repository root:

```sh
vp -C apps/my-app dev --host 0.0.0.0 --port 5173
```

At `http://localhost:5173`, you see **My Radical app** and browser device information.

</Step>
<Step>

## Open a native shell

Run in a second terminal:

<Tabs items={["Android", "iOS"]}>
<Tab value="Android">

```sh
adb reverse tcp:5173 tcp:5173
cd apps/my-app
pnpm exec radical android
```

You see the heading and `platform: "android"`.

</Tab>
<Tab value="iOS">

```sh
cd apps/my-app
pnpm exec radical ios
```

You see the heading and `platform: "ios"`.

</Tab>
</Tabs>

</Step>
<Step>

## Stop the server

Press Control-C in the dev-server terminal.

</Step>
</Steps>

Continue with [device targets](/docs/guides/run-on-a-device) or [bundled delivery](/docs/guides/bundled-mode).
