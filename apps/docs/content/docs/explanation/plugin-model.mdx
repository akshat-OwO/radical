A manifest connects a JavaScript command contract to native implementations. The same Effect Schema codecs supply argument types, result validation, and rejection mapping.

Custom plugins stay disabled until listed in config. Internal `device` and `transitions` default to enabled; other capabilities are opt-in. Required implications override explicit false flags.

## Build contracts and runtime contracts stay separate

Browser-safe manifests describe commands. Build-only contributions add camera descriptions, Firebase files, entitlements, and runtime defines. Conflicting plist values fail generation instead of depending on plugin order.

Generated clients preserve schema-derived types. Type generation neither installs missing packages nor implements native methods. Changing the plugin set requires native regeneration.

[Add a typed native plugin](/docs/guides/custom-plugins) contains the authoring procedure. [Plugin manifest reference](/docs/reference/plugins) lists fields and error rules.
