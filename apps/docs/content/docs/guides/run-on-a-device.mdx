## Prerequisites

Install Node.js 22.18+ and pnpm. Start with [installation](/docs/getting-started/installation) and the [native toolchain setup](/docs/getting-started/native).

For capability guides, install dependencies from the app directory, set the specified flags in Vite config, then regenerate:

<Tabs items={["Android", "iOS"]}>
<Tab value="Android">

```sh
pnpm exec radical android --generate-only
```

</Tab>
<Tab value="iOS">

```sh
pnpm exec radical ios --generate-only
```

</Tab>
</Tabs>

See the [generation pipeline](/docs/explanation/native-shells).

## Launch a target

<Tabs items={["Android", "iOS"]}>
<Tab value="Android">

<Steps>
<Step>

### Prepare Android

Install the SDK, platform tools, compatible JDK, and an AVD or authorized USB device.

| Tool discovery | Set                                           |
| -------------- | --------------------------------------------- |
| SDK            | `ANDROID_HOME` or `ANDROID_SDK_ROOT`          |
| Executables    | Alternatively, `adb` and `emulator` on `PATH` |

</Step>
<Step>

### Connect localhost

Start the dev server with `devHost: "localhost"`, then reverse its port. The TanStack CLI template uses port 3000; use the port Vite prints if yours differs:

```sh
adb -s YOUR_SERIAL reverse tcp:3000 tcp:3000
```

</Step>
<Step>

### Launch

Pass a serial or installed AVD name from the app directory:

```sh
pnpm exec radical android --target YOUR_SERIAL_OR_AVD
```

You see your app on the selected target.

</Step>
</Steps>

</Tab>
<Tab value="iOS">

<Steps>
<Step>

### Select a simulator

On macOS with Xcode, list simulator UDIDs:

```sh
xcrun simctl list devices available
```

</Step>
<Step>

### Launch

Run from the app directory:

```sh
pnpm exec radical ios --target YOUR_SIMULATOR_UDID
```

You see your app in the simulator.

</Step>
</Steps>

For physical devices, generate only, open `.radical/ios/ios/App` in Xcode, configure signing, and run.

</Tab>
</Tabs>

## Use a LAN server

| Setting   | Value                                      |
| --------- | ------------------------------------------ |
| Vite bind | `--host 0.0.0.0`                           |
| `devHost` | Device-reachable address                   |
| `origin`  | Update or remove if overriding the dev URL |

<Callout type="warning">
  Remote offline support requires HTTPS; plain HTTP LAN origins cannot register
  workers.
</Callout>

See [target defaults](/docs/reference/cli).
