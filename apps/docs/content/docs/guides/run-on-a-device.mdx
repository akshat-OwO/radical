<Tabs items={["Android", "iOS"]}>
<Tab value="Android">

<Steps>
<Step>

### Prepare the target

Install the Android SDK, platform tools, a compatible JDK, and an AVD, or authorize a USB device. Set `ANDROID_HOME` or `ANDROID_SDK_ROOT`, or put `adb` and `emulator` on `PATH`.

</Step>
<Step>

### Connect the server

For localhost, reverse the server port and set `devHost: "localhost"`:

```sh
adb -s YOUR_SERIAL reverse tcp:5173 tcp:5173
```

Start Vite on port 5173 before generating. For a LAN connection, follow **Use a LAN server** below.

</Step>
<Step>

### Generate and launch

Pass an adb serial or installed AVD name from the app directory:

```sh
pnpm exec radical android --target YOUR_SERIAL_OR_AVD
```

</Step>
</Steps>

</Tab>
<Tab value="iOS">

<Steps>
<Step>

### Select a simulator

On macOS with Xcode, list available simulator UDIDs:

```sh
xcrun simctl list devices available
```

</Step>
<Step>

### Generate and launch

From the app directory, pass the simulator UDID:

```sh
pnpm exec radical ios --target YOUR_SIMULATOR_UDID
```

For a physical device, generate with `radical ios --generate-only`. Open `.radical/ios/ios/App` in Xcode, configure signing, and run there.

</Step>
</Steps>

</Tab>
</Tabs>

## Use a LAN server

Bind Vite with `--host 0.0.0.0` and set `devHost` to the reachable address. Update or remove `origin` if it overrides the recorded dev URL.

<Callout type="warning">
  For remote offline support, use HTTPS. Plain HTTP LAN origins cannot register
  service workers.
</Callout>

See [CLI reference](/docs/reference/cli) for target defaults and [Native shell generation](/docs/explanation/native-shells) for the pipeline.
