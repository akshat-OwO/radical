---
title: "Handle notification taps"
description: "Own notification navigation in the app scope."
---

<Steps>

<Step>

### Mount the app watcher

In your root component, obtain the router with `useRouter()`.

In a mount effect, start a scoped watcher:

```ts
const fiber = Effect.runFork(
  Effect.scoped(
    watchNotificationNavigation({ appId: config.appId, push: true })
  ).pipe(
    Effect.provide(
      Layer.mergeAll(
        BridgeLive,
        NotificationSnapshotsLive.pipe(Layer.provide(BridgeLive)),
        tanstackStartAdapterLayer(router)
      )
    )
  )
);
```

</Step>

<Step>

### Release the watcher on unmount

In the effect cleanup, interrupt the fiber with `Effect.runFork(Fiber.interrupt(fiber))`.

</Step>

<Step>

### Configure notification routes

If you use only local notifications, omit `push: true`.

Put an app-relative path in a local notification's `route` or a push notification's `data.route`.

For an offline destination, mark the route offline and visit its exact URL after worker activation.

</Step>

</Steps>

Keep the watcher mounted when you leave the notification screen. Import watcher services from `radical/client` and `tanstackStartAdapterLayer` from `radical/tanstack-start-client`. The [example root](https://github.com/akshat-OwO/radical/blob/main/apps/example/src/routes/__root.tsx) has the complete imports and lifecycle.
