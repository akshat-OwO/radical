---
title: "Configure Firebase push"
description: "Register a native push token and manage topic subscriptions."
---

<Steps>
<Step>

### Prepare Firebase

Create Firebase apps matching your native identifiers:

| Platform | Identifier         | App-owned, gitignored file |
| -------- | ------------------ | -------------------------- |
| Android  | Package identifier | `google-services.json`     |
| iOS      | Bundle identifier  | `GoogleService-Info.plist` |

</Step>
<Step>

### Enable push

Complete [local notification setup](/docs/guides/notifications), then apply [capability setup](/docs/guides/run-on-a-device#prerequisites) with `internalPlugins.pushNotifications: true`:

```sh
pnpm add @capacitor-firebase/messaging@8.5.2
```

</Step>
<Step>

### Configure platforms

Set file paths before regenerating:

<Tabs items={["Android", "iOS"]}>
<Tab value="Android">

```ts
notifications: {
	android: { googleServices: "./private/google-services.json" },
},
```

</Tab>
<Tab value="iOS">

```ts
notifications: {
	ios: {
		googleServiceInfo: "./private/GoogleService-Info.plist",
		environment: "development", // "production" for distribution
	},
},
```

Match signing and entitlements to your provisioning profile; configure APNs credentials in Firebase for distribution.

</Tab>
</Tabs>

</Step>
<Step>

### Register and manage topics

Send the successful `value` token through your authenticated backend API:

```ts
const notifications = useNotifications(); // @akshatowo/radical/react
notifications.registerPush();
notifications.subscribe("reports");
notifications.unsubscribe("reports");
notifications.lookupTopics(); // Confirmed topics for this installation
```

</Step>
</Steps>

<Callout type="warning">
  Keep Firebase files out of Git; send messages through your backend.
</Callout>

See [Notifications reference](/docs/reference/notifications).
