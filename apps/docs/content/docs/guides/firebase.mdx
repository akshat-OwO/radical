---
title: "Configure Firebase push"
description: "Register a native push token and manage topic subscriptions."
---

<Steps>

<Step>

### Prepare Firebase apps

Configure Firebase apps with your Android package identifier and iOS bundle identifier.

Add the Firebase Android and iOS configuration files to app-owned, gitignored paths.

</Step>

<Step>

### Enable push dependencies

Install the local notification dependencies from [Schedule a local notification](/docs/guides/notifications).

Install `@capacitor-firebase/messaging@8.5.2` and set `internalPlugins.pushNotifications: true`.

</Step>

<Step>

### Set platform configuration

Configure the file paths:

```ts
notifications: {
	android: { googleServices: "./private/google-services.json" },
	ios: {
		googleServiceInfo: "./private/GoogleService-Info.plist",
		environment: "development",
	},
},
```

For distribution, set `notifications.ios.environment` to `"production"` and configure APNs credentials in Firebase.

</Step>

<Step>

### Regenerate the shells

Regenerate both shells. Keep signing and push entitlements consistent with your provisioning profile.

</Step>

<Step>

### Register and store the token

Call `notifications.registerPush()` from `useNotifications()`. Read the FCM token from `value` after success.

Send the token to your backend through your authenticated API.

</Step>

<Step>

### Manage topics

To subscribe, call `notifications.subscribe("reports")`. To unsubscribe, call `notifications.unsubscribe("reports")`.

To read this installation's confirmed topic list, call `notifications.lookupTopics()`.

</Step>

</Steps>

<Callout type="warning">Keep Firebase configuration files out of Git.</Callout>

Send messages through your backend. See [Notifications reference](/docs/reference/notifications).
