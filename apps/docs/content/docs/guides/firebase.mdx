---
title: "Configure Firebase push"
description: "Register a native push token and manage topic subscriptions."
---

1. Configure Firebase apps with your Android package identifier and iOS bundle identifier.
2. Add the Firebase Android and iOS configuration files to app-owned, gitignored paths.
3. Install the local notification dependencies from [Schedule a local notification](/docs/guides/notifications).
4. Install `@capacitor-firebase/messaging@8.5.2` and set `internalPlugins.pushNotifications: true`.
5. Configure the file paths:

```ts
notifications: {
	android: { googleServices: "./private/google-services.json" },
	ios: {
		googleServiceInfo: "./private/GoogleService-Info.plist",
		environment: "development",
	},
},
```

6. For distribution, set `notifications.ios.environment` to `"production"` and configure APNs credentials in Firebase.
7. Regenerate both shells. Keep signing and push entitlements consistent with your provisioning profile.
8. Call `notifications.registerPush()` from `useNotifications()`. Read the FCM token from `value` after success.
9. Send the token to your backend through your authenticated API.
10. To subscribe, call `notifications.subscribe("reports")`. To unsubscribe, call `notifications.unsubscribe("reports")`.
11. To read this installation's confirmed topic list, call `notifications.lookupTopics()`.

Send messages through your Firebase backend. Radical does not expose a message-sending server API. Never commit Firebase configuration files. See [Notifications reference](/docs/reference/notifications).
