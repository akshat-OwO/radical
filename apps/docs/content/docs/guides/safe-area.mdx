---
title: "Keep content inside the safe area"
description: "Apply initial insets and subscribe to later changes."
---

Apply safe-area insets to keep content clear of system bars and native navigation.

<Steps>
<Step>

## Configure the viewport

Add to the document head:

```html
<meta
  name="viewport"
  content="width=device-width, initial-scale=1, viewport-fit=cover"
/>
```

</Step>
<Step>

### Provide context

Use the [root setup](/docs/guides/bundled-mode#configure-the-root) with `<RadicalProvider nativeContext={nativeContext}>`.

</Step>
<Step>

### Apply insets

Apply `safeAreaStyle(nativeContext, config.mode)` to `<html>` and pad content:

```css
main {
  padding-top: calc(var(--radical-safe-area-top) + 16px);
  padding-bottom: calc(var(--radical-safe-area-bottom) + 16px);
  padding-left: calc(var(--radical-safe-area-left) + 16px);
  padding-right: calc(var(--radical-safe-area-right) + 16px);
}
```

You see content inside the device's safe area.

</Step>
<Step>

### Observe changes

Read component state with `useSafeArea()` from `@akshatowo/radical/react`.

</Step>
</Steps>

<Callout type="warning">

Do not add keyboard height to safe-area insets.

</Callout>

See the [keyboard contract](/docs/reference/safe-area).
