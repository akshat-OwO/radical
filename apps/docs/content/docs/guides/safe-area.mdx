---
title: "Keep content inside the safe area"
description: "Apply initial insets and subscribe to later changes."
---

1. Add `viewport-fit=cover` to the viewport meta tag.
2. For remote mode, obtain `context.nativeContext` through the Radical request middleware and a server function in the root loader.
3. Pass that context to `<RadicalProvider nativeContext={nativeContext}>`.
4. Apply `safeAreaStyle(nativeContext, config.mode)` to `<html>`.
5. Add the CSS variables to your content padding:

```css
main {
  padding-top: calc(var(--radical-safe-area-top) + 16px);
  padding-bottom: calc(var(--radical-safe-area-bottom) + 16px);
  padding-left: calc(var(--radical-safe-area-left) + 16px);
  padding-right: calc(var(--radical-safe-area-right) + 16px);
}
```

6. For component state, call `useSafeArea()` from `radical/react`.
7. For bundled mode, follow the mount setup in [Switch to bundled mode](/docs/guides/bundled-mode).

Do not add keyboard height to the safe-area insets. See the [safe-area model](/docs/reference/safe-area) for the keyboard contract.
