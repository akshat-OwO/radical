---
title: "Keep content inside the safe area"
description: "Apply initial insets and subscribe to later changes."
---

<Steps>

<Step>

### Configure the document

Add `viewport-fit=cover` to the viewport meta tag.

</Step>

<Step>

### Provide initial context

<Tabs items={["Remote", "Bundled"]}>
<Tab value="Remote">

Obtain `context.nativeContext` through Radical request middleware and a server function in the root loader. Pass it to `<RadicalProvider nativeContext={nativeContext}>`.

</Tab>
<Tab value="Bundled">

Use `localNativeContext()` in the loader and `mountNativeContext()` after mount. Follow [Switch to bundled mode](/docs/guides/bundled-mode) for the complete setup.

</Tab>
</Tabs>

</Step>

<Step>

### Apply inset styles

Apply `safeAreaStyle(nativeContext, config.mode)` to `<html>`.

Add the CSS variables to your content padding:

```css
main {
  padding-top: calc(var(--radical-safe-area-top) + 16px);
  padding-bottom: calc(var(--radical-safe-area-bottom) + 16px);
  padding-left: calc(var(--radical-safe-area-left) + 16px);
  padding-right: calc(var(--radical-safe-area-right) + 16px);
}
```

</Step>

<Step>

### Observe live insets

For component state, call `useSafeArea()` from `radical/react`.

</Step>

</Steps>

<Callout type="warning">
  Do not add keyboard height to safe-area insets.
</Callout>
See the [safe-area model](/docs/reference/safe-area) for the keyboard contract.
