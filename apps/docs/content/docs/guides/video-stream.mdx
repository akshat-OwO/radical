---
title: "Preview the camera and scan QR codes"
description: "Mount a viewfinder and control a live video session."
---

<Steps>
<Step>

## Enable preview

Apply [capability setup](/docs/guides/run-on-a-device#prerequisites) with `internalPlugins.videoStream: true` and `pluginOptions.VideoStream.usageDescription`:

```sh
pnpm add @capgo/camera-preview@8.14.2
```

</Step>
<Step>

### Mount a viewfinder

Give the mounted element nonzero dimensions:

```tsx
const viewfinder = useRef<HTMLDivElement>(null);
const stream = useVideoStream({ viewfinder, onDetect: setLastQR });
// Render inside your component:
<div ref={viewfinder} style={{ width: "100%", height: "40vh" }} />;
```

</Step>
<Step>

### Prepare native transparency

Copy the [transparent viewfinder and opaque surrounding layout](https://github.com/akshat-OwO/radical/blob/main/apps/example/src/routes/video.tsx).

</Step>
<Step>

### Connect controls

Connect supported actions to buttons:

| Action | Call | Condition |
| --- | --- | --- |
| Start or stop | `stream.start()`, `.stop()` | User action |
| Switch camera | `stream.switchCamera()` | Active session |
| Zoom | `stream.setZoom(level)` | Within `value.zoom.min` and `.max` |
| Torch | `stream.setTorch(true)` | `value.torchAvailable` |
| QR detection | Read detection results | `detectionAvailable`; browser needs `BarcodeDetector` |

You see the live preview after starting.

</Step>
</Steps>

Handle `stream.error`; stop when finished. Unmount releases the camera.

See [Video stream reference](/docs/reference/video-stream).
