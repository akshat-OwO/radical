---
title: "Read device information"
description: "Display device metadata after mount."
---

<Steps>
<Step>

### Read device state

Keep the default `internalPlugins.device` enabled and call:

```ts
const device = useDeviceInfo(); // radical/react
```

| State     | Render                          |
| --------- | ------------------------------- |
| `loading` | Placeholder                     |
| `error`   | Handled `_tag`                  |
| Success   | `value.platform`, `value.model` |

You see [device metadata](/docs/reference/device-info) after mount.

</Step>
</Steps>

<Callout type="warning">
  Do not authorize requests with browser device information.
</Callout>
