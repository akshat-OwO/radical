---
title: "Read device information"
description: "Display device metadata after mount."
---

<Steps>

<Step>

### Enable device info

Keep `internalPlugins.device` enabled. It is enabled by default.

</Step>

<Step>

### Read the hook state

In your component, call `useDeviceInfo()` from `radical/react`.

While `loading` is true, display a placeholder.

If `error` exists, display or handle its `_tag`.

Otherwise, read `value.platform`, `value.model`, and the other [device fields](/docs/reference/device-info).

</Step>

</Steps>

For Effect callers, run `getDeviceInfo.pipe(Effect.provide(BridgeLive))` after mount. Do not use browser device information to authorize a request.
