---
title: "Add a typed native plugin"
description: "Enable a Schema-defined manifest and call its commands."
---

<Steps>
<Step>

### Define the manifest

Copy the [Echo manifest](https://github.com/akshat-OwO/radical/blob/main/apps/example/plugins/echo.ts), following the [manifest contract](/docs/reference/plugins).

</Step>
<Step>

### Enable the plugin

Configure your manifest:

```ts
plugins: [{ manifest: "./plugins/echo.ts" }],
pluginOptions: { Echo: { prefix: "Native: " } },
```

</Step>
<Step>

### Generate declarations

Include `.radical/plugins.d.ts` in `tsconfig.json` before running:

```sh
pnpm exec radical typegen
```

[Regenerate shells](/docs/guides/run-on-a-device#prerequisites) after manifest or native-source changes.

</Step>
<Step>

### Call the command

Run this Effect from your lifecycle or event handler:

```ts
import { Effect } from "effect";
import { BridgeLive } from "radical/client";
import { plugins } from "virtual:radical/plugins";

const echo = plugins.echo.echo({ text: "hello" }).pipe(
  Effect.catchTag("EchoRejected", (error) =>
    Effect.succeed({ text: error.reason })
  ),
  Effect.provide(BridgeLive)
);
```

You receive the native Echo result or handled rejection.

</Step>
</Steps>

See the [bridge sequence](/docs/explanation/bridge).
