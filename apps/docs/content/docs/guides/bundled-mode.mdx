---
title: "Switch to bundled mode"
description: "Package the UI while keeping server functions on your API origin."
---

See the [delivery flow and authentication constraints](/docs/explanation/delivery-modes).

<Steps>
<Step>

### Configure delivery

Pass this config to both `tanstackStart(tanstackStartOptions(config))` and `radical(config)` from `@akshatowo/radical/tanstack-start`:

```ts
const config = {
  appId: "dev.example.app",
  mode: "bundled",
  origin: "https://api.example.com",
} satisfies RadicalConfig;
```

</Step>
<Step>

### Configure Start

Set `src/start.ts`:

```ts
import { createStart } from "@tanstack/react-start";
import { createRadicalFetch } from "@akshatowo/radical/client";
import { createRadicalRequestMiddleware } from "@akshatowo/radical/tanstack-start-server";
import { config } from "virtual:radical/config";

export const startInstance = createStart(() => ({
  defaultSsr: config.mode !== "bundled",
  requestMiddleware: [...createRadicalRequestMiddleware()],
  serverFns: { fetch: createRadicalFetch(config) },
}));
```

</Step>
<Step>

### Wrap the API

Keep the explicit bundled-request wrapper in `src/server.ts`:

```ts
import {
  createStartHandler,
  defaultStreamHandler,
} from "@tanstack/react-start/server";
import {
  offlineHandler,
  withBundledRequests,
} from "@akshatowo/radical/tanstack-start-server";

export default {
  fetch: withBundledRequests(
    createStartHandler(offlineHandler(defaultStreamHandler))
  ),
};
```

</Step>
<Step>

### Configure the root

Apply the [complete root setup](https://github.com/akshat-OwO/radical/blob/main/apps/example/src/routes/__root.tsx) for each mode:

<Tabs items={["Bundled", "Remote"]}>
<Tab value="Bundled">

```tsx
// Root loader:
await localNativeContext();
// Route component:
<ClientOnly>
  <Outlet />
</ClientOnly>;
// Mount effect:
mountNativeContext();
```

Keep startup loaders independent of unavailable APIs.

</Tab>
<Tab value="Remote">

Keep the server-function native-context loader and render `<Outlet />` directly.

</Tab>
</Tabs>

| Shared setup | Use |
| --- | --- |
| Document style | `safeAreaStyle(nativeContext, config.mode)` |
| Offline registration | `registerOffline({ mode: config.mode, ... })` |
| Other API requests | `createRadicalFetch(config)` |
| Build outputs | Keep Start's `dist/client`, `_shell.html`, and Vite base `/` |

</Step>
<Step>

### Run the shell

[Regenerate and launch](/docs/guides/run-on-a-device).

You see the packaged UI without fetching its initial document from the API.

</Step>
</Steps>

For a local API, build, then run from the app directory:

```sh
pnpm exec vp preview --host 0.0.0.0 --port 4173
```

Set `origin` to a device-reachable address.

<Callout type="warning">
  Custom Vite CORS must use `cors: false` or an origin callback returning
  `false` for both bundled origins. Static lists can consume preflights before
  `withBundledRequests`.
</Callout>
