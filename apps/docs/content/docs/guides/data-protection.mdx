---
title: "Protect sensitive content and clear web data"
description: "Enable native screen protection and delete local WebView data."
---

1. Set `internalPlugins.dataProtection: true` and regenerate both shells.
2. Call `useDataProtection()` from `radical/react`.
3. Before showing sensitive content, call `protection.setEnabled(true)`.
4. Read the returned status to determine which protections the platform supports.
5. When the protected flow ends, call `protection.setEnabled(false)`. Unmount does not disable protection.
6. Before clearing data, stop app writes, close other tabs, and close IndexedDB connections.
7. From an explicit user action, call `protection.clearWebData()`.
8. If `error` exists, handle the failure before assuming local data is gone.

Clearing removes accessible storage, cookies, databases, caches, and worker registrations, plus native WebView data. A failure can occur after some data is already deleted. Reload or navigate to your signed-out screen after success. See [Data protection reference](/docs/reference/data-protection) for platform limits.
