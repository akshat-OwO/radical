---
title: "Protect sensitive content and clear web data"
description: "Enable native screen protection and delete local WebView data."
---

<Steps>

<Step>

### Enable protection

Set `internalPlugins.dataProtection: true` and regenerate both shells.

Call `useDataProtection()` from `radical/react`.

</Step>

<Step>

### Protect the sensitive flow

Before showing sensitive content, call `protection.setEnabled(true)`.

Read the returned status to determine which protections the platform supports.

When the protected flow ends, call `protection.setEnabled(false)`. Unmount does not disable protection.

</Step>

<Step>

### Clear local data

Before clearing data, stop app writes, close other tabs, and close IndexedDB connections.

From an explicit user action, call `protection.clearWebData()`.

If `error` exists, handle the failure before assuming local data is gone.

</Step>

</Steps>

<Callout type="warning">
  Clearing can fail after partial deletion. Handle errors before assuming local
  data is gone.
</Callout>

After success, reload or navigate to your signed-out screen. See [Data protection reference](/docs/reference/data-protection) for deletion scope and platform limits.
