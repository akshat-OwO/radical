---
title: "Protect sensitive content and clear web data"
description: "Enable native screen protection and delete local WebView data."
---

<Steps>
<Step>

### Enable protection

[Configure and regenerate](/docs/guides/run-on-a-device#prerequisites) with `internalPlugins.dataProtection: true`.

</Step>
<Step>

### Protect content

Enable protection before showing sensitive content and disable it when the flow ends:

```ts
const protection = useDataProtection(); // @akshatowo/radical/react
protection.setEnabled(true);
// After the sensitive flow:
protection.setEnabled(false);
```

Read the returned status for supported protections.

</Step>
<Step>

### Clear data

Stop writes, close other tabs and IndexedDB connections, then call from an explicit user action:

```ts
protection.clearWebData();
```

After success, reload or show your signed-out screen.

</Step>
</Steps>

<Callout type="warning">
  Unmount does not disable protection. Clearing can fail after partial deletion;
  handle `protection.error` before assuming data is gone.
</Callout>

See [deletion scope and platform limits](/docs/reference/data-protection).
