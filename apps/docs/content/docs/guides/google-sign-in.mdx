---
title: "Configure Google sign-in"
description: "Obtain an identity token in Android and iOS shells."
---

<Steps>

<Step>

### Create OAuth clients

In Google Cloud, create a web OAuth client and an iOS OAuth client. Match the iOS client to your configured bundle identifier.

For Android, configure the OAuth client with the package identifier and signing certificate fingerprint for your build.

</Step>

<Step>

### Enable sign-in

Install `@capawesome/capacitor-google-sign-in@0.1.4`.

Set `internalPlugins.googleSignIn: true`.

</Step>

<Step>

### Set public client identifiers

Read your public client identifiers from environment variables in Vite config:

```ts
pluginOptions: {
	GoogleSignIn: {
		webClientId: process.env.GOOGLE_WEB_CLIENT_ID,
		iosClientId: process.env.GOOGLE_IOS_CLIENT_ID,
	},
},
```

Set both environment variables before generation. Use values ending in `.apps.googleusercontent.com`. Do not commit real identifiers in the example config.

</Step>

<Step>

### Regenerate the shells

Regenerate both shells. Radical writes the iOS `GIDClientID` and reversed URL scheme.

</Step>

<Step>

### Sign in and verify the token

Call `useGoogleSignIn()` from `radical/react` and invoke `signIn()` from a button.

After success, send `value.idToken` to your backend for verification and session creation. Do not treat an unverified token as an authenticated session.

Handle `GoogleSignInCancelled` separately from configuration failures.

</Step>

</Steps>

The default browser implementation returns `GoogleSignInUnavailable`. For a browser flow, provide your own `BrowserGoogleSignIn` service. See [Google sign-in reference](/docs/reference/google-sign-in).
