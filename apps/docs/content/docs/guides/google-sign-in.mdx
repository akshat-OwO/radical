---
title: "Configure Google sign-in"
description: "Obtain an identity token in Android and iOS shells."
---

Ask Google to identify the user, then send the identity token to your server.

<Steps>
<Step>

## Create OAuth clients

Configure Google Cloud clients:

| Client  | Match                                            |
| ------- | ------------------------------------------------ |
| Web     | Backend audience                                 |
| iOS     | Bundle identifier                                |
| Android | Package identifier and build signing fingerprint |

</Step>
<Step>

### Enable sign-in

Apply [capability setup](/docs/guides/run-on-a-device#prerequisites) with `internalPlugins.googleSignIn: true`:

```sh
pnpm add @capawesome/capacitor-google-sign-in@0.1.4
```

</Step>
<Step>

### Configure identifiers

Set both environment variables to `.apps.googleusercontent.com` identifiers before generation:

```ts
pluginOptions: {
	GoogleSignIn: {
		webClientId: process.env.GOOGLE_WEB_CLIENT_ID,
		iosClientId: process.env.GOOGLE_IOS_CLIENT_ID,
	},
},
```

Keep real identifiers out of example config.

</Step>
<Step>

### Sign in

Connect a button to:

```ts
const google = useGoogleSignIn(); // @akshatowo/radical/react
google.signIn();
```

Handle `GoogleSignInCancelled` separately.

</Step>
</Steps>

<Callout type="warning">

Verify `value.idToken` on your backend before creating a session.

</Callout>

See [browser service and errors](/docs/reference/google-sign-in).
