---
title: "Set app identity, icon, and splash"
description: "Configure generated Android and iOS names and images."
---

<Steps>

<Step>

### Set identity

Set a shared `appId` and `name` in your Radical config.

If a platform needs another identity, set `android.packageId`, `android.name`, `ios.bundleId`, or `ios.name`.

</Step>

<Step>

### Prepare source images

Add a square PNG or JPEG icon of at least 1024 pixels per side.

Add a square PNG or JPEG splash image of at least 2732 pixels per side.

Configure paths relative to the app root:

```ts
icon: { image: "./assets/icon.png", backgroundColor: "#6d28d9" },
splash: { image: "./assets/splash.png", backgroundColor: "#241044" },
```

</Step>

<Step>

### Regenerate the shells

Regenerate both shells with `radical android --generate-only` and `radical ios --generate-only` from the app directory.

</Step>

</Steps>

Use opaque six-digit RGB hex colors. See [Config reference](/docs/reference/config) for validation rules.
