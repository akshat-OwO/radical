---
title: "Set app identity, icon, and splash"
description: "Configure generated Android and iOS names and images."
---

Keep your app name, icon, and splash inputs outside the generated native projects.

<Steps>
<Step>

## Set identity

Set shared identity and optional platform overrides:

```ts
appId: "dev.example.app",
name: "My app",
// android: { packageId: "dev.example.android", name: "Android app" },
// ios: { bundleId: "dev.example.ios", name: "iOS app" },
```

</Step>
<Step>

### Add images

Configure app-relative PNG or JPEG paths and opaque six-digit RGB colors:

```ts
icon: { image: "./assets/icon.png", backgroundColor: "#6d28d9" },
splash: { image: "./assets/splash.png", backgroundColor: "#241044" },
```

| Image  | Minimum square dimensions |
| ------ | ------------------------- |
| Icon   | 1024 × 1024               |
| Splash | 2732 × 2732               |

</Step>
<Step>

### Generate assets

[Regenerate the shells](/docs/guides/run-on-a-device#prerequisites).

You see the configured name, icon, and splash in the generated app.

</Step>
</Steps>

See [config validation](/docs/reference/config).
