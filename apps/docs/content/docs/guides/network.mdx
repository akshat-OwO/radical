---
title: "Observe network connectivity"
description: "Update your UI when the connection changes."
---

<Steps>
<Step>

### Enable network status

Apply [capability setup](/docs/guides/run-on-a-device#prerequisites) with `internalPlugins.network: true`:

```sh
pnpm add @capacitor/network@8.0.1
```

</Step>
<Step>

### Render connectivity

Read the hook state:

```ts
const network = useNetworkStatus(); // radical/react
```

| State     | Render                                    |
| --------- | ----------------------------------------- |
| `loading` | Unknown                                   |
| `error`   | Handled `_tag`                            |
| Success   | `value.connected`, `value.connectionType` |

You see updates when local connectivity changes.

</Step>
</Steps>

Check endpoint availability with an application request. See [Network reference](/docs/reference/network).
