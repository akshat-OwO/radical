---
title: "Animate route navigation"
description: "Enable slide or fade transitions with TanStack Router."
---

<Steps>
<Step>

### Install transitions

Configure `src/router.tsx` once after creating the router:

```ts
import "@akshatowo/radical/transitions.css";
import { browserTransitions } from "@akshatowo/radical/tanstack-start-client";

const transitions = browserTransitions(router);
// Retain transitions.cancel() and transitions.dispose() for teardown.
```

</Step>
<Step>

### Choose a transition

Set destination route static data:

```ts
staticData: { radical: { transition: "slide" } }, // or "fade"
```

</Step>
<Step>

### Verify navigation

If disabled, enable `internalPlugins.transitions` and [regenerate](/docs/guides/run-on-a-device#prerequisites) before navigating through Router links.

You see the selected transition. With `"slide"`, history back reverses the slide direction. With `"fade"`, navigation fades in both directions.

</Step>
</Steps>
