---
title: "Animate route navigation"
description: "Enable slide or fade transitions with TanStack Router."
---

<Steps>

<Step>

### Install transitions

In `src/router.tsx`, import `radical/transitions.css`.

After creating the router, call `browserTransitions(router)` from `radical/tanstack-start-client` once.

</Step>

<Step>

### Select a route transition

On each destination route, set a transition:

```ts
staticData: { radical: { transition: "slide" } },
```

To use a fade, set `transition: "fade"` instead.

</Step>

<Step>

### Regenerate and verify navigation

If you disabled `internalPlugins.transitions`, enable it and regenerate both shells.

Navigate through Router links or `router.navigate` to check the transition. Use history back to check the reverse slide.

</Step>

</Steps>

For cancellation and teardown, retain the installer's returned `cancel()` and `dispose()` methods. See [Transitions reference](/docs/reference/transitions).
