---
title: "Pick and open files"
description: "Select attachments and hand native files or URLs to other apps."
---

<Steps>
<Step>

### Enable file capabilities

Apply [capability setup](/docs/guides/run-on-a-device#prerequisites) for the operations you need:

| Operation | Install | Enable |
| --- | --- | --- |
| Pick | `@capawesome/capacitor-file-picker@8.1.1` | `internalPlugins.filePicker` |
| Open externally | `@capacitor/app-launcher@8.0.1`, `@capacitor-community/file-opener@8.0.1` | `internalPlugins.intents` |

</Step>
<Step>

### Pick attachments

Connect a button to these `radical/react` hooks:

```ts
const picker = useFilePicker();
const intent = useIntent();
picker.pick({ types: ["application/pdf"], multiple: true });
```

You receive files with bytes in `picker.value[i].blob`.

</Step>
<Step>

### Open externally

Choose an action:

```ts
intent.openFile(file);
intent.openFile(file, { chooser: true });
intent.openUrl("https://example.com/help");
```

Handle `picker.error` and `intent.error` separately.

</Step>
</Steps>

<Callout type="warning">
  Selections load into memory; avoid very large files.
</Callout>

See [browser restrictions and file errors](/docs/reference/files).
