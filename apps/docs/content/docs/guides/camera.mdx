---
title: "Capture or choose a photo"
description: "Enable still-camera capture and a single-image library picker."
---

<Steps>
<Step>

### Enable capture

Apply the [capability setup](/docs/guides/run-on-a-device#prerequisites) with this dependency and config:

```sh
pnpm add @capacitor/camera@8.2.6
```

```ts
internalPlugins: { camera: true },
pluginOptions: {
	Camera: {
		usageDescription: "Take a photo to attach to your report.",
		photoLibraryUsageDescription: "Choose a photo to attach to your report.",
	},
},
```

</Step>
<Step>

### Connect actions

Connect these `radical/react` hooks to user actions:

```ts
const camera = useCamera();
const permission = useCameraPermission();
// Buttons:
permission.request();
camera.capture();
camera.choose();
// After returning from settings:
permission.check();
```

</Step>
<Step>

### Show the image

Disable actions while `camera.loading` and render successful results:

```tsx
<img src={camera.value.dataUrl} alt="Selected attachment" />
```

You see the captured or selected photo.

</Step>
</Steps>

<Callout type="warning">
  Keep the hook mounted until the picker closes. Interruption cannot dismiss it.
</Callout>

See [errors and browser behavior](/docs/reference/camera).
