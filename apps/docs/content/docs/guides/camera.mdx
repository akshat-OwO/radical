---
title: "Capture or choose a photo"
description: "Enable still-camera capture and a single-image library picker."
---

<Steps>

<Step>

### Enable the camera

Install `@capacitor/camera@8.2.6` in your app.

Set `internalPlugins.camera: true`.

Add both usage descriptions to your config:

```ts
pluginOptions: {
	Camera: {
		usageDescription: "Take a photo to attach to your report.",
		photoLibraryUsageDescription: "Choose a photo to attach to your report.",
	},
},
```

</Step>

<Step>

### Regenerate the shells

Regenerate both shells.

</Step>

<Step>

### Connect the hooks

In a component, call `useCamera()` and `useCameraPermission()` from `radical/react`.

To request permission from a user action, call `permission.request()`.

To capture, call `camera.capture()`. To choose one image, call `camera.choose()`.

</Step>

<Step>

### Display the result

While `camera.loading` is true, disable the action button. On success, display `<img src={camera.value.dataUrl} alt="Selected attachment" />`.

If the user returns from system settings, call `permission.check()` to refresh the state.

</Step>

</Steps>

<Callout type="warning">
  Keep the hook mounted until the native picker closes. Interruption cannot
  dismiss it.
</Callout>

See [Camera reference](/docs/reference/camera) for errors and browser behavior.
