---
title: "Send haptic feedback"
description: "Add feedback to a completed action or selection."
---

Send haptic feedback after a user action succeeds, fails, or changes a selection.

<Steps>
<Step>

## Enable haptics

Apply [capability setup](/docs/guides/run-on-a-device#prerequisites) with `internalPlugins.haptics: true`:

```sh
pnpm add @capacitor/haptics@8.0.2
```

</Step>
<Step>

### Connect feedback

Call the hook in your component:

```ts
const feedback = useHapticFeedback(); // @akshatowo/radical/react
```

| Trigger | Call |
| --- | --- |
| Success | `feedback.success()` |
| Selection | `feedback.selection()` |
| Impact | `feedback.light()`, `.medium()`, `.heavy()`, or `.impact("HEAVY")` |
| Warning | `feedback.warning()` |
| Error | `feedback.error()` |
| Failure handling | Read `feedback.failure` |

</Step>
</Steps>

<Callout type="warning">

Success does not prove the hardware vibrated.

</Callout>

See [Haptics reference](/docs/reference/haptics).
