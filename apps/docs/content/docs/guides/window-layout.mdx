---
title: Adapt to window layout
description: Adapt your page to window width and folds.
---

<Callout type="info">

Window layout is available in `@akshatowo/radical` 0.3.0 and later.

</Callout>

Pass your loader's `nativeContext` to `RadicalProvider`, as in the [installation guide](/docs/getting-started/installation). Use `useWindowLayout()` to choose your layout:

```tsx
import { useWindowLayout } from "@akshatowo/radical/react";

function Content() {
  const { widthClass, posture } = useWindowLayout();
  return (
    <main data-width={widthClass} data-posture={posture}>
      ...
    </main>
  );
}
```

Use `compact`, `medium`, and `expanded` to choose columns or control placement. On Android, use `tabletop` and `book` to adapt to half-open folds.

See [width limits and posture values](/docs/reference/window-layout).

To expose hinge bounds to CSS from the first render, merge `windowLayoutStyle` into your `<html>` style:

```tsx
import { safeAreaStyle, windowLayoutStyle } from "@akshatowo/radical/client";

const style = {
  ...safeAreaStyle(nativeContext, config.mode),
  ...windowLayoutStyle(nativeContext, config.mode),
};

// In your document component:
return <html style={style}>{children}</html>;
```

Use `--radical-hinge-x`, `--radical-hinge-y`, `--radical-hinge-width`, and `--radical-hinge-height` to keep controls clear of the hinge. Bounds use CSS pixels from the window's top-left corner.

Without a hinge, all four values are `0px`.

Keep the loader context for the first render. The hook applies live values after mount.

Without the style merge, the shell adds hinge variables only after mount, so hydration still matches. Bundled pages start with `compact`, `flat`, and no hinge; native CSS applies after mount.
