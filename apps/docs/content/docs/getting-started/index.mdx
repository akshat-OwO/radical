title: "Getting started"
description: "Create a TanStack Start app, run it in your browser, then open it on Android or iOS."
---

Radical adds native shells and device APIs to your web app. Your app lives in its own project.

TanStack Start handles routing and rendering in both remote and bundled mode.

Start with a browser app. You need a native toolchain only when you run Android or iOS.
