The [installation](/docs/getting-started/installation) adds Radical to a generated app. This example uses pnpm. Your add-ons and package manager can add other files. After the first dev run, inspect the files with `find src public .radical -type f`.

```text
my-app/
├── public/
│   └── offline.html
├── src/
│   ├── routes/
│   │   ├── __root.tsx
│   │   ├── device.tsx
│   │   └── index.tsx
│   ├── router.tsx
│   ├── routeTree.gen.ts       # Generated by TanStack Start
│   ├── server.ts
│   ├── start.ts
│   └── styles.css            # Generated stylesheet
├── .radical/                 # Generated by Radical
├── package.json
├── pnpm-workspace.yaml
├── pnpm-lock.yaml
├── tsr.config.json
├── tsconfig.json
└── vite.config.ts
```

## App files

| File | Purpose |
| --- | --- |
| `vite.config.ts` | App identity, delivery mode, native capabilities, and Vite plugins |
| `src/start.ts` | Request middleware and typed server-function context |
| `src/server.ts` | SSR handler and offline response headers |
| `src/router.tsx` | Router instance and optional navigation integrations |
| `src/routes/__root.tsx` | HTML document, native-context loader, provider, and safe-area layout |
| `src/routes/index.tsx` | Your existing `/` page |
| `src/routes/device.tsx` | Device information at `/device` |
| `public/offline.html` | Standalone fallback for remote offline loading |

TanStack Start discovers file routes inside `src/routes`. For example, `src/routes/about.tsx` defines `/about`. See [TanStack file-based routing](https://tanstack.com/router/latest/docs/framework/react/routing/file-based-routing) for nested and dynamic routes.

## Generated files

The CLI generates `src/router.tsx` and the initial route files. The installation creates or extends `src/start.ts` and `src/server.ts`. Start maintains `src/routeTree.gen.ts`. Change route files instead of editing the generated tree.

Radical writes metadata and generated plugin types under `.radical` during Vite configuration and startup. Native commands generate `.radical/android` and `.radical/ios`. Builds write web output to `dist`.

Add these entries to `.gitignore`:

```text
node_modules/
.radical/
.tanstack/
dist/
```

Native projects are disposable build output. Keep identity, assets, permissions, and plugin settings in your Vite config and app-owned files. Regeneration replaces native projects, so direct changes there do not survive.
