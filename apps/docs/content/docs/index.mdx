Radical runs your web app inside Android and iOS WebViews. It loads the UI from an HTTP origin in remote mode or packages SPA assets in bundled mode.

The framework-agnostic Vite plugin generates native projects. The Plain API and React hooks expose native capabilities. The Effect API provides typed composition through `/effect/*` subpaths. Your app keeps control of routing, rendering, data fetching, and HTTP handling.

## Works with your framework

TanStack Start is the only supported framework adapter today. It supports both remote and bundled mode.

## Where the UI lives

| Mode | UI source | Server work | Offline startup |
| --- | --- | --- | --- |
| Remote, the default | Configured HTTP origin | Documents and data | Visited route snapshots or packaged fallback |
| Bundled | Packaged SPA assets | API and server functions | Packaged UI; remote data needs app-owned handling |

Both modes share the native bridge. Browser support depends on each capability.

## Platform boundaries

| Capability | Android | iOS | Browser |
| --- | --- | --- | --- |
| CLI build and run | Gradle and adb; emulator or USB device | Xcode on macOS; iPhone simulator | Vite dev server |
| Physical device | CLI with adb target | App-owned signing and Xcode run | Not applicable |
| Native APIs | Enabled manifests | Enabled manifests | Capability-specific web services |
| UI delivery | Remote or bundled | Remote or bundled | Web origin |

Radical does not provide authentication, store distribution, or a database. Native context describes presentation and cannot prove identity.
