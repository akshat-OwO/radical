---
title: "Radical runs your web app in native shells"
description: "An introduction to Radical for developers who already use server-rendered web apps."
---

Radical is a Vite plugin and runtime that runs your web app inside Android and iOS WebView shells. You keep your framework's routing, server rendering, data fetching, and HTTP server. Radical generates the native projects and connects your UI to native capabilities through a typed bridge.

Radical fits teams that want to share a web UI with mobile apps while keeping a server-rendered framework. TanStack Start is the implemented framework adapter. React hooks expose camera capture, files, Google sign-in, haptics, network status, notifications, safe area, live video, device info, and data protection. Custom native plugins use Effect Schema contracts.

## Two modes select where the UI lives

| Mode | UI source | Server work | Offline startup |
| --- | --- | --- | --- |
| Remote mode | Your configured HTTP origin | Your framework renders documents and handles data calls | Previously visited offline routes use snapshots. A packaged offline fallback covers missing snapshots. |
| Bundled mode | SPA assets packaged in the shell | Your configured remote API handles server functions and data calls | Packaged UI starts without a UI server. Data still needs your API unless your app handles its absence. |

Remote mode is the default. Both modes use the same bridge and native capabilities. Browsers use capability-specific fallbacks.

## Platform support has boundaries

The native shells use Capacitor 8. Android runs through Gradle and adb. The iOS CLI runs iPhone simulators through Xcode on macOS. Physical iOS devices require your own Xcode signing and run setup. Browser support varies by capability and browser API.

Radical does not provide authentication, app-store distribution, a database, or a replacement router. Native context describes presentation and never proves identity.
